In light of Google replacing its dictionary feature with AI overview, I created a simple English dictionary browser extension. It is a lightweight toolbar popup that displays definitions with examples, pronunciations, synonyms, and antonyms.

It uses the <a href="https://dictionaryapi.dev" target="_blank">Free Dictionary API</a> and the code can be found <a href="https://github.com/RoryByrne1/dictionrory" target="_blank">on my GitHub</a>. It's also available as a <a href="https://addons.mozilla.org/en-GB/firefox/addon/dictionrory" target="_blank">Firefox add-on</a>.
